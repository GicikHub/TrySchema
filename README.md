📖 O projekcie

Wypożyczalnia Rowerów to aplikacja konsolowa napisana w języku C++, umożliwiająca podstawowe zarządzanie rowerami w wypożyczalni.

Program pozwala dodawać rowery, wypożyczać je, zwracać oraz sprawdzać ich aktualny status i cenę wynajmu.

Projekt został stworzony w celu praktycznego wykorzystania podstawowych mechanizmów programowania w języku C++.
